# Build log: 2026-11-24

Production Phase 6: the Action & Report Kit replaces the Encrypted Vault (owner decision, 2026-11-23). Branch `phase-6`, created from `main` at `d436055` (the merge of PR #5, Phase 5b). Local commits only: no push, no deploy, no pull request.

## Built
- **The Action & Report Kit**, under every result on `/check` in every band (`src/components/ActionKit.tsx`, logic and every fixed string in `src/lib/actionKit.ts`). Built in the browser from the check just run: no network call, no storage, nothing sent or opened for the person, no CSP change (`src/lib/csp.ts` is untouched; a Blob download is not a fetch).
  - **Copy report text** and **Download this summary** (a client-side Blob `.txt`, fixed name `offer-check-summary.txt`, the same content). The text holds the band wording, the plain names of the findings that fired (`CHECK_LABELS`), the channel the person picks (Email, WhatsApp, LinkedIn, Offer letter or PDF, Other), a free-text box (what they type, cut to 1,000 characters) and the `authorities.ts` channels with the existing reporting note. It never holds offer text, an evidence quote, a name, a phone number or an email address unless the person types one. It is not called an official packet and claims no channel's format. MoI and Aman stay the UAE Government directory links (defects LINK-2).
  - **Three fixed WhatsApp replies**, copy only (decline politely; ask for the MOHRE offer reference number; continue only through official channels). No wa.me link, nothing opens.
  - **Official links** and the missed-scam form link (`MissedScamLink`, moved into the Kit).
  - **Not a clearance.** Under Low and Medium, the owner's exact line is shown in the result banner and is the last paragraph before the official channels in the copied text.
- **The Vault is removed.** Nav tab, `/vault` page (308 to `/check` in `next.config.ts`), Save button and modal, `EncryptedVault`, `VaultTools`, `vaultStore`. Vault wording is gone from Settings, Privacy, Terms, About, the footer, the install note and the Arabic dictionary.
- **Privacy and Terms** now say the Kit is created on the device from the person's own check and nothing is sent; the statements about saving, the passphrase, export and import are removed. Terms gained a short Kit section.
- **Footer line** (after the owner review): "The server does not store the text you check or its result. The Action & Report Kit is built in this browser." It matches `/privacy`; the earlier "Nothing you check is saved" was stronger than the facts, because the server keeps daily counts and a check's audit entries (length, rule ids, score) exist in page memory until reload.
- **Header**: four tabs (Analyzer; Portals, Guidelines, About). Measurements re-run, see Checks.
